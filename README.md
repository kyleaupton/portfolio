# Portfolio

Welcome to the repository for my personal portfolio website. This site is built using Nuxt 4, Nuxt UI, Nuxt Content, and TypeScript. This website showcases other projects I've worked on and offers a mechanism to view their READMEs.

## Getting Started

Ensure you have the following installed:
* Node.js (v22.5 or higher)
* npm

```bash
# Clone repo
git clone https://github.com/kyleaupton/portfolio.git

# Install deps
cd portfolio
npm install
```

## Development

To start the development server

```bash
npm run dev
```

## Production

This project is intended to be ran in production with Docker.

## Deployment

The site is configured for Continuous Deployment (CD) to my self-hosted Coolify instance. Any commit to main will trigger a build there.
